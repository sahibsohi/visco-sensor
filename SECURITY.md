# Security policy

## Reporting

Do not open a public issue for a vulnerability involving secrets, authentication, personal data, or unsafe health-related behavior. Contact the repository owner privately with reproduction steps and the affected component.

## Data handling

This repository must contain synthetic demonstration data only. Do not submit protected health information, real patient records, credentials, or production connection strings.

## Scope

The software is an educational prototype and has not undergone the security, privacy, regulatory, or clinical reviews required for medical use.
